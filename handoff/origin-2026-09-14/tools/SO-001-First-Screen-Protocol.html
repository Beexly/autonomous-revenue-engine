SO-001 First Screen Protocol

Signal Origin kill gate. One page. Applied before anything is ranked, published, or sold. Not a writing service. Not a subscription. Not sports.

0. Purpose

Stop work that already looks finished. Polished interchangeability is the failure mode. If a hundred AI-operator accounts could run the line after the byline is removed, it does not ship. The gate is applied once, in this order. Do not skip a step because the prose is clean.

1. Order of operations

  1. Swap test. Fail = Kill. Stop.
  2. Bait screen. Below 6 = Kill. Stop. Below 9 = no Hold.
  3. Staccato screen. One- or two-word stacks = no Hold. Repeat stacks = Kill.
  4. Density. Below 8 = no Hold.
  5. Composite. Hold only at ≥ 9.2 with all floors met.
  6. Cut list. Remove what survived by charm.
  7. Rank only what Hold. Never rank a Kill to “see if it hits.”

2. Swap test (binary)

Cover the byline, the product name, and any house vocabulary. Read the line as if it ran under a different operator account tomorrow.

  • KILL if the claims, cadence, and moral would still work as a generic “AI writing / quality / authenticity” post.
  • PASS only if a specific observation, number, constraint, or refusal would break if the byline changed.

A detector rubric that can be quoted is not a swap-test pass. If the model can study the rule, the rule is already leaking. Do not publish extra scoring commentary that teaches the next rewrite.

3. Scoring floors

AxisWeightHold floorWhat you are actually scoring
Swap / non-interchangeability 0.30 binary pass Would this line still work under a stolen byline?
First-screen density 0.25 ≥ 8 Facts, constraints, names, numbers, refusals per screen. No throat-clearing.
Bait avoidance 0.25 ≥ 9 No engagement hooks, no “agree?”, no empty dares, no emoji stacks, no hashtag spam.
Lived particularity 0.20 contributes to composite Something happened, was measured, or was killed. Not a stance.

Composite = 10 × (0.30·S + 0.25·D/10 + 0.25·B/10 + 0.20·P/10) where S is 1 if swap passed, else 0 (and you already stopped).

HOLD only if: composite ≥ 9.2 AND density ≥ 8 AND bait ≥ 9 AND no one/two-word staccato stacks.

7.0–9.19: soft rewrite, same facts, tighter first screen.
Below 7.0, or bait < 6: hard rewrite or kill. Do not polish a Kill until it “sounds human.”

4. Cut list (apply after floors, before rank)

If any item is true, cut the clause. If three items are true, kill the piece.

  1. Symmetric two-clause hook (“X isn’t Y. It’s Z.”).
  2. Cluster diction: leverage, delve, tapestry, landscape, robust, seamless, unlock, nested, “the future of.”
  3. A rule that explains itself enough to be trained on.
  4. A pitch in the first sentence.
  5. A question whose only job is a reply.
  6. A second offer, a subscription, a “we also,” a writing package.
  7. Sports, GSE, NFL, Texans, or any borrowed audience.
  8. Invented metrics, rounded “studies show,” unverified follower counts.
  9. Hashtags, emoji as emphasis, “comment below.”
  10. A line that would still rank if the proper nouns were swapped for competitors.

6. Worked kill

Line: “In a world of AI slop, originality is the real moat. Agree?”

  • Swap: fail. Any operator account can run it.
  • Bait: 3 (the agree?).
  • Density: 2 (no fact).
  • Staccato: none, irrelevant.
  • Kill at step 1. Do not rewrite toward Hold. Write a different line from a real kill, measurement, or refusal.

Line: “Seven of our own themes scored 6.0 to 6.5 under one critic. The spread was 0.5. That is interchangeable work that still shipped.”

  • Swap: pass (the corpus is named and would break if stolen without the measurement).
  • Bait: 9.5 (no hook).
  • Density: 9 (two numbers, one claim, one consequence).
  • Composite: Hold. Rank on irreversible particular.
