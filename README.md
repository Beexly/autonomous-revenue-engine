# Project Flower

A garden is counted, not announced.

```
    6   12  15  23  5   18
    F    L   O   W  E    R
```

Beds are numbered.
Cultivar names are not posted at the gate.
If you were sent a cutting, you already know which row.

This repository is a working plot.
Instruments live under `docs/` and `apps/`.
Paper that does not bloom is composted.

## Growth Ops blueprint

Use the growth-ops handoff package to plan and implement the charcuteriechick.ai rebuild:

- `docs/architecture.md` - end-to-end system architecture and hosting decisions
- `docs/flywheel-90-day.md` - 90-day operating plan, cadences, KPIs, and review template
- `docs/runbooks/ops-checklist.md` - daily/weekly/monthly operating checklist and incident playbooks
- `data/sql/` - PostgreSQL schema and attribution views
- `services/automation/workflows/` - implementation-ready n8n workflow specifications
