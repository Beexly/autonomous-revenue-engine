## Rules for this folder

- **`FACTS.md` is the only place a price or claim may come from.** If it is not
  there, ask the owner — never infer, never invent.
- Client-facing builds carry **real photos only**. No AI-generated imagery, no
  stock. Quarantine lists live in each client's `ASSETS.md`.
- Every quote, scope change and delivery promise goes in that client's
  `QUOTE.md` before it is said out loud.
- Live builds are static HTML: no framework, no build step, hand-editable.
