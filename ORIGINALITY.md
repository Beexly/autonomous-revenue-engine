# Originality Scoring Gate

Every asset must pass this gate before any public release.

## Scoring Dimensions (0-10 each)
1. Authorship clarity — is the core idea/angle/data clearly human-origin?
2. Added value density — how much unique analysis, framing, or transformation is present?
3. Novelty vs recent high-engagement content in the same topic space
4. Automation risk — any signals of raw model output or low-effort generation?
5. Transformation quality (if source material is used)
6. Alignment with X Original Content Rewards language

## Pass Threshold
Minimum total 42/60. Any single dimension below 5 = automatic reject or rewrite.

## Disqualifiers (instant fail)
- Copied or substantially reproduced content
- Re-upload from another platform without meaningful transformation
- Pure automated output
- Minor edits only (caption, crop, filter, overlay)
- Engagement bait primary purpose
- Misleading claims

## Process
1. Draft generated under production rules
2. Score against the six dimensions
3. Adversarial review
4. Final pass/fail logged
5. Only pass assets move to publish queue
