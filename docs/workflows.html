Lead Catcher

Never miss a lead after hours again. When a potential customer calls and you can't answer, the system sends an instant text-back and captures their details in your CRM.

Demo: How it works

This is a mock demonstration. Incoming call → SMS auto-reply with custom message → Lead added to Google Sheets/CRM → Notification sent to your phone.

Deliverables

Custom SMS auto-reply script, CRM integration (Google Sheets or Airtable), setup guide.

$0 Stack

n8n (self-hosted), Twilio free tier (or email SMS gateway), Google Sheets.

Failure Handling

If SMS fails, falls back to email. Webhook retries with exponential backoff. Admin notified via email after 3 failed attempts.

Price

Setup: $250 | Monthly: $0 (self-hosted)

Review Engine

Automatic review requests after jobs, with responses drafted for one-tap approval. Build your reputation on autopilot.

Demo: How it works

This is a mock demonstration. Job marked complete → Review request sent → Customer replies → Response drafted for your approval → One-tap post to Google/Facebook.

Deliverables

Automated review request workflow, response template library, approval interface.

$0 Stack

n8n (self-hosted), Gmail API, Google Sheets for tracking.

Failure Handling

If customer doesn't respond, follow-up after 3 days. If approval not given, draft expires after 24 hours. System logs all actions for review.

Price

Booking Flow

Quote → approve → schedule → reminder texts. No-shows die.

Demo: How it works

This is a mock demonstration. Customer requests quote → You send quote → Customer approves → System schedules job → Automated reminders sent 24h and 2h before.

Deliverables

Quote-to-booking workflow, calendar integration (Google Calendar), automated reminder system.

$0 Stack

n8n (self-hosted), Google Calendar, Twilio free tier (for SMS reminders).

Failure Handling

If calendar busy, suggests alternative times. If reminder fails, attempts via email. Customer can reschedule via link in reminder.

Price

Setup: $200 | Monthly: $0 (self-hosted)
