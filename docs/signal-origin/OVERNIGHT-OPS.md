## Reply checklist (the short gate)

Originals use qi-check Hold ≥ 9.2. Replies use this, all must be yes:

1. Adds a **mechanism, distinction, or cost** the parent did not already state.
2. Would still make sense if the Signal Origin handle were hidden.
3. No hashtags, no emoji piles, no "Great take", no "This.", no "Let's go", no CTA, no link, no pitch for Kit/Gumroad/qi-check.
4. No team-jersey politics. If the parent is political, either find the technical object or skip.
5. ≤ 240 characters preferred. One idea. Periods allowed. No staccato slogan stack ("Clean structure. Not policy. Quality.").
6. Does not claim measurements we did not take.
7. Sounds like a person who has shipped something annoying, not a brand.

Fail any item → kill the draft. Do not Soft-rewrite a bad parent into a manifesto.
