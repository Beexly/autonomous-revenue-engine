DIY: the free 15-point checklist

This is the real checklist, not a teaser.

  1. Inventory events. Events Manager → Data sources → your Pixel. List every event arriving via Browser, Server, or Both. Anything business-critical (Purchase, Lead, InitiateCheckout) should be Both.
  2. Check dedup status. For each "Both" event, look for deduplicated statistics. Meta dedupes when browser and server send the same event_name + event_id. No shared event_id means double-counting.
  3. Verify event_id generation. The same unique id must be produced once per user action and passed to both the Pixel call and the CAPI payload.
  4. Confirm the dedup window. Server event must arrive within 48h of the browser event; send within minutes. Nightly CAPI batches of Pixel-already-sent events double-count.
  5. Score EMQ per event. Events Manager shows Event Match Quality (1–10) for server events. Record the number. Do not claim a target until you measured it.
  6. Fix EMQ inputs. email (em) and phone (ph) as SHA-256 of lowercase/trimmed values, external_id, fbp/fbc, client IP + user agent on website events.
  7. Normalize before hashing. Lowercase, trim, strip formatting BEFORE SHA-256 (phone digits). Hashing mixed-case emails silently kills match rate.
  8. Check action_source. Server events must carry the true source (website, etc.).
  9. Forward fbp/fbc. Include _fbp and, when a click id exists, fbc.
  10. Use Test Events before trusting anything. Test events + test_event_code on server payloads. Watch browser + server rows arrive and dedupe live.
  11. Reconcile against your backend. Pick 7 days. Compare Meta-reported Purchases vs actual orders. Within ~5–15% is normal; 30%+ high often means double-counting.
  12. Check coverage after consent banners. Test as a consent-declined visitor.
  13. Look for rejected/filtered events. Diagnostics tab. Address every active issue.
  14. Verify domain + aggregated setup. Domain verified in Business Manager.
  15. Re-check after every theme/app/checkout change. Calendar a monthly pass of items 2, 5, 11, 13.
