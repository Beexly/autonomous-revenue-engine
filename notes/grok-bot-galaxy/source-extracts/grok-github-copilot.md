## Grok 4.5 in GitHub Copilot

Grok 4.5, our smartest coding model, is now available in GitHub Copilot.

Try Grok 4.5 in the APIOpen GitHub Copilot

Grok 4.5 is now available in GitHub Copilot for millions of developers who use VSCode and GitHub products every day.

### Getting started

GitHub Copilot spans multiple products, including cloud agents, the Copilot CLI, and the VSCode IDE. From the model picker, simply pick "Grok 4.5" to start using our latest coding model. For some businesses and enterprises, you will need to enable the model from Copilot settings.

Grok 4.5 is also available directly from the SpaceXAI console at $2 per million input tokens and $6 per million output tokens. For more on the model, including coding performance, read the Grok 4.5 announcement.
